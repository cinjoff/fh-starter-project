# Design

## Aesthetic Direction

This is a **template project** — the design is intentionally neutral. It uses the default Shadcn/ui theme (New York variant, neutral palette) so users can customize it for their specific project via `/fh:teach-impeccable`.

## Base Design Tokens

- **Colors:** Shadcn/ui default neutral palette (zinc-based)
- **Typography:** Geist Sans (body) + Geist Mono (code)
- **Radius:** Shadcn default (0.5rem)
- **Spacing:** Tailwind v4 defaults

## Component Library

- **Shadcn/ui** — default neutral theme, components installed on demand
- **Phosphor Icons** — consistent icon set, use regular weight by default

## Principles

1. Clean and minimal — no visual opinions that fight the user's future design
2. Accessible by default (WCAG AA)
3. Dark mode support via Tailwind `dark:` variant
4. Responsive from the start
