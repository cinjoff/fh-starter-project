# Phase 1 Context — Design Decisions

## Locked Decisions

### Biome + ESLint Coexistence
- **Biome**: formatting + general JS/TS/CSS linting (replaces Prettier)
- **ESLint**: slim config with `eslint-config-next/core-web-vitals` only (Next.js-specific rules)
- Both run in lint-staged pre-commit hook
- Scripts: `check` (biome), `lint` (eslint), `format` (biome format --write)

### Sentry Integration Strategy
- **Skip `withSentryConfig` wrapper** in next.config.ts — avoids Turbopack/webpack conflicts
- Rely on manual instrumentation files (already scaffolded): `instrumentation.ts`, `instrumentation-client.ts`, `sentry.server.config.ts`
- Source maps: handle via Sentry CLI in CI (Phase 4), not build plugin
- This is safer for Next.js 16's Turbopack-first approach

### Shadcn/ui Preset
- Preset: `b3XobJslQO` (Lyra) — `radix-lyra` style, Phosphor icons, neutral base
- No separate `@phosphor-icons/react` install needed — shadcn Lyra preset includes it
- `components.json` generated by `pnpm dlx shadcn@latest init --preset b3XobJslQO`
