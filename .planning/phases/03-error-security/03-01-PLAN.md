<task type="auto">
  <name>Task 1: Security headers in proxy.ts</name>
  <files>src/proxy.ts</files>
  <action>
  1. In `src/proxy.ts`, after calling `updateSession(request)`, apply security headers to the returned response.
  2. Create a `applySecurityHeaders(response)` helper within the file.
  3. Headers to set:
     - `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`
     - `X-Frame-Options: DENY`
     - `X-Content-Type-Options: nosniff`
     - `Referrer-Policy: strict-origin-when-cross-origin`
     - `Permissions-Policy: camera=(), microphone=(), geolocation=()`
     - `Content-Security-Policy`: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' https: data:; font-src 'self' data:; connect-src 'self' ${sentry + supabase origins}; frame-ancestors 'none'`
  4. Read Supabase URL and Sentry DSN from env vars to build CSP connect-src dynamically.
  5. Ensure headers are applied to both normal responses AND redirects.
  </action>
  <verify>Run `pnpm build` to confirm no errors. Read the proxy.ts file and verify all 6 header categories are present.</verify>
  <done>Every response from proxy includes all security headers. CSP connect-src includes self plus any configured Sentry/Supabase origins.</done>
</task>
