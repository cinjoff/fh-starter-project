## [0.1.0] - 2026-03-20

### Added

- Next.js 16 + React 19 + TypeScript project scaffold
- Shadcn/ui component library with Lyra preset
- Supabase client packages (auth + SSR)
- Sentry error tracking with local SQLite dev mode
- Biome formatting and linting
- Husky + lint-staged pre-commit hooks
- t3-env environment variable validation
- Three-layer error boundaries (ErrorBoundary, error.tsx, global-error.tsx)
- Phosphor Icons
- Sonner toast notifications
- React Hook Form + Zod resolver
- date-fns date utilities
- nuqs URL state management
- ActionState<T> type for server actions
- SubmitButton component with pending state
- Production metadata template (OG, Twitter, title template)
